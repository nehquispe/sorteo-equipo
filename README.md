# Sorteo de Grupos

Aplicación web para registrar 18 o 24 participantes, organizarlos manualmente o al azar en seis grupos, asignar cartas por palo y formar equipos finales de seis integrantes.

## Funciones

- Drag and drop y selección mediante pulsación prolongada.
- Sorteo aleatorio de grupos y cartas.
- Edición manual después del sorteo.
- Equipos finales agrupados por Corazones, Diamantes, Tréboles y, con 24 personas, Espadas.
- Exportación de la distribución final como JPG.
- Compartir mediante el menú nativo del teléfono, incluyendo WhatsApp cuando esté disponible.
- Guardado automático local.

La publicación en GitHub Pages se realiza automáticamente con GitHub Actions.
